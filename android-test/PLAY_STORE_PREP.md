Short description: Employee attendance, work hours and event management for ZIBALD SECURITY.
Full description: ZIBALD SECURITY TEST is an internal testing application for employee attendance and work-hour management. Authorized managers can review attendance reports and event information. This test build connects only to the isolated test environment.
