# משמרון — Android

אפליקציה אחת לכל הארגונים: נחי (001), אסף (002), נטו ג׳וב (003), זיוולד המקורי (004), מאסטר (005). סביבת בדיקה מבודדת זמינה באמצעות קוד 000. פרטי התחברות נשארים בשרת הארגון; הקוד אינו מכיל סיסמאות או נתוני עובדים.

Package: `il.co.mishmaron.app`; version 1.0.0 (1); Android 8+; target SDK 36.

## בנייה

JDK 17, Android SDK 36 ו־Build Tools 35.0.0. הגדירו `ANDROID_HOME` או `local.properties`, ואז הריצו בתיקייה זו:

```sh
./gradlew testDebugUnitTest lintRelease assembleDebug assembleRelease bundleRelease
```

תוצרי release אינם חתומים בבנייה הרגילה. מפתח ההעלאה נשמר בנפרד מהמאגר. אין להשתמש במפתח debug לפרסום ב־Play ואין להכניס מפתחות או סיסמאות ל־Git. תהליך CI בונה ובודק בלבד ואינו שולח או מפרסם ב־Google Play.

## לקוח עתידי

הוסיפו רשומה ל־`config/organizations.json` בענף `mishmaron-play-all-clients`: קוד ייחודי, שם הארגון וכתובת HTTPS ראשית. בדקו שהשרת הוא שרת מאושר של משמרון ושהתנהגותו תואמת להצהרות הפרטיות. עדכנו גם את העותק ב־`android/app/src/main/assets/organizations.json` לבנייה הבאה. אין לפרסם כאן פרטי כניסה. לאחר שמירת הרשימה בענף, אפליקציות קיימות מרעננות אותה בפתיחה; במקרה תקלה נשמרת הרשימה האחרונה או זו שהגיעה עם האפליקציה. שינוי בסוגי המידע או בתפקוד מחייב בדיקה ועדכון הצהרות, גם בלי שינוי קוד Android.

## גבולות והרשאות

WebView מאפשר רק את מקור ה־HTTPS של הארגון שנבחר. מעבר ארגון מוחק את חיבור המכשיר והאחסון המקומי של הדפדפן; מידע בשרת אינו נמחק. חזרה לאותו ארגון שומרת חיבור. אין JavaScript bridge, קוד צד שלישי לפרסום/אנליטיקה או מיקום ברקע. תמונה מתקבלת ממצלמת המכשיר או מבורר קבצים מערכתי, ללא הרשאת גישה גורפת לתמונות. הרשאת מיקום מבוקשת בעת הדיווח בלבד, עם הסבר על העברה לארגון ושמירה בשרת. ניתן לבחור מיקום מקורב במכשירים תומכים.

קובץ `config/privacy-function.ts` הוא מקור עמוד הפרטיות הציבורי ונתיב בקשת המחיקה, המתאר גם את מידע הנוכחות והשכר. שינויים בעמוד זה דורשים פריסה נפרדת לשירות `mishmaron-privacy`; שינוי הקובץ ב־Git לבדו אינו פורס אותו.

## לפני הפצה

נדרשת בדיקה בטלפון של כל מסלול: בחירת ארגון, כניסת עובד ומנהל, מתן וסירוב הרשאות, תמונה ממצלמה ומבורר, דיווח כניסה ויציאה בסביבת הבדיקה, ייצוא דוח, כפתור חזרה, סגירה/פתיחה והחלפת ארגון. בדיקות היחידה מכסות גבולות URL ואינן מחליפות בדיקת מכשיר. אין לשלוח ל־Google לבדיקה לפני אישור מפורש של בעל החשבון.
